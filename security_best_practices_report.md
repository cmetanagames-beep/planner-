# Отчёт по безопасности и стабильности Lumo

Дата проверки: 3 августа 2026 года.

## Результат

Проведён полный аудит PWA, Express API, SQLite-хранилища, Dev Console, GitHub Pages workflow и эксплуатационных скриптов. Найдено 18 подтверждённых проблем исходного состояния: 5 высокого, 9 среднего и 4 низкого уровня. Все 18 проблем исправлены в текущей версии проекта.

## Что исправлено

- Изоляция пользователей, семей и облачных копий; защищено подтверждение дел от имени другого пользователя.
- Семейные коды сделаны криптографически случайными и более длинными, добавлены ограничения частоты запросов.
- Закрыты сохранённые XSS через семейные поручения, покупки, импорт и облачное восстановление.
- Добавлена строгая нормализация импортируемых и синхронизируемых данных.
- Ограничены размеры резервных копий, изображений и чеков; большие фото уменьшаются перед OCR.
- Запрещена регистрация произвольного push-адреса; разрешены только HTTPS-адреса поддерживаемых push-провайдеров.
- Идентификаторы расписания изолированы по пользователям, а поля расписания ограничены по типу и размеру.
- Создание облачных копий ограничено; повторное создание возвращает существующую копию и не заполняет диск.
- OCR-библиотека размещена локально и закреплена на конкретной версии.
- GitHub Actions закреплены на точных SHA, а Dev Console исключена из публикации на общем origin PWA.
- Токены и содержимое Telegram-отчётов больше не передаются через аргументы командной строки и не выводятся в журнал.
- Добавлены защитные HTTP-заголовки и скрыта сигнатура Express.

## Проверки

- Контракт безопасности сервера: 17/17.
- Dev Console: DOM 55/55, страницы 6/6, API 6/6.
- Семейные сценарии: 4/4.
- Ядро помощника: 39/39.
- Реальные и стрессовые фразы помощника: 243/243.
- Изолированный API-тест: разграничение пользователей, безопасная нормализация, облачная квота, защита push и HTTP-заголовки — пройден.
- Telegram-доставка — пройдена реальным тестовым сообщением.
- Мобильный интерфейс 390×844, светлая и тёмная темы, помощник, привычки и настройки проверены в браузере без ошибок консоли и горизонтального переполнения.

## Сервер

Рабочий процесс PM2 запущен, health-check отвечает успешно. На VPS около 2 ГБ RAM и 25 ГБ диска; по результатам проверки свободных ресурсов достаточно, увеличение памяти сейчас не требуется.

## Эксплуатационная рекомендация

Секреты, когда-либо отправленные в чат или показанные на скриншоте, следует отозвать и выпустить заново после публикации. Сам код больше не раскрывает их в выводе процессов или журнале.
