# Lumo backend

Секретные ключи не хранятся в `index.js`. Перед первым запуском скопируйте
`.env.example` в `.env` и заполните `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY` и
остальные используемые параметры. Файл `.env` исключён из Git.

Этот каталог содержит Node.js API для push-уведомлений, семьи, синхронизации и собственного распознавания речи `whisper.cpp`.

Пользовательские маршруты защищены автоматически созданным 256-битным токеном устройства. Клиент один раз регистрирует пару `userId + token`, после чего сервер проверяет заголовки `X-Lumo-User` и `X-Lumo-Device-Token` и запрещает подмену `userId` в теле запроса. Разрешённые браузерные источники задаются через `CLIENT_ORIGINS`, а базовый адрес одноразовой QR-ссылки — через `CLIENT_URL`.

## Запуск

```bash
npm ci
cp .env.example .env
npm start
```

На рабочем VPS процесс запускается через PM2:

```bash
pm2 start index.js --name push
pm2 save
```

Секреты и базы данных не коммитятся. Для голосового API сначала запусти `bash scripts/install-whisper.sh`. Скрипт устанавливает всё в домашний каталог без `sudo`; модель задаётся переменной `WHISPER_MODEL_NAME`, по умолчанию используется многоязычная `base`.

## Диагностика

`GET /health` — публичная минимальная проверка доступности. Закрытый
`GET /developer/status` требует заголовок `x-developer-token`, совпадающий с
`DEVELOPER_TOKEN` из `.env`. Он возвращает только обезличенную статистику и
используется отдельной PWA из `app/dev`. Создать ключ на VPS можно командой:

```bash
node ../scripts/setup-developer-token.mjs .env
```
